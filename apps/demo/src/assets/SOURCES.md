# Demo assets

The conversation between Codex, Claude, and Kimi is fictional demo content.

- `kapeka.jpg`: profile image supplied by Kapeka for the demo.

Astro emits the supplied profile image as a 96 px WebP avatar.

SVG logos come from [Lobe Icons](https://github.com/lobehub/lobe-icons), package version 1.95.0:

- `codex.svg`: [Codex color SVG](https://unpkg.com/@lobehub/icons-static-svg@1.95.0/icons/codex-color.svg).
- `claude.svg`: [Claude color SVG](https://unpkg.com/@lobehub/icons-static-svg@1.95.0/icons/claude-color.svg).
- `kimi.svg`: [Kimi color SVG](https://unpkg.com/@lobehub/icons-static-svg@1.95.0/icons/kimi-color.svg).

Claude and Kimi have padded, solid backgrounds for overlapping avatars. The logo paths are unchanged. The Lobe Icons MIT license is included in `LOBE-ICONS-LICENSE`; trademarks belong to their respective owners.
